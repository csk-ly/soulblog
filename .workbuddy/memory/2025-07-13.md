### 发现的主要问题（按优先级）

1. **安全（P0）**：`consts.ts` 中 `NEXT_PUBLIC_GITHUB_ENCRYPT_KEY` 硬编码在客户端，加密密钥暴露
2. **SEO（P1）**：`lang='en'` 应为 `zh-CN`；缺少 OG 图片、sitemap、metadataBase
3. **性能（P1）**：首页全客户端渲染（`'use client'`），无 SSR；大量 `<img>` 未用 `next/image`；Starfield 脚本绕过 Next.js Script 优化
4. **可访问性（P1）**：`user-scalable=no` 禁用缩放；可点击元素缺少 aria-label
5. **代码质量（P2）**：`aritcle-card` 拼写错误；定位逻辑重复耦合；config-store 浅拷贝；`let` 应为 `const`
6. **UX（P2）**：移动端隐藏过多功能卡片；首屏白屏闪烁；布局编辑保存逻辑令人困惑

## 星空粒子背景升级（starfield.js v2.0）

用户反馈粒子效果不够炫酷，只是由远及近直线飘。

重写了 `public/starfield.js`（v1.5 → v2.0），API 接口不变，新增四层数学变换：
1. **螺旋角速度**：ω = K/(d+K)，离中心越近旋转越快，形成银河旋臂效果
2. **Perlin 噪声扰动**：二维 Perlin 噪声场扭曲粒子轨迹，产生有机非线性路径
3. **正弦脉冲**：径向速度 v = v(1 + A·sin(ωt + φ))，形成呼吸式波纹
4. **色相循环**：HSL 色相 H = (H + d·k + t·s) % 360，颜色持续流转

渲染增强：
- `globalCompositeOperation = 'lighter'` 加法混合，粒子重叠处自然发光
- 双线宽描边：宽透明线 + 窄亮线，模拟辉光
- 中心原点径向渐变脉冲光晕

同时更新了 `src/layout/backgrounds/starfield.tsx` 的配置参数。

### v2.1 性能与拖尾优化

用户反馈 v2.0 太卡，且拖尾鬼影（绿色楔形/弧线）持续太久不消失。原因是 `lighter` 加法混合 + 75% 长拖尾 + 螺旋/噪声弯曲让粒子划过的区域留下 10 帧左右的累积轨迹。

调整参数：
- numStars 300→200（CPU 降低 33%）
- trailLength 0.75→0.4（拖尾从 10 帧缩短到 3-4 帧）
- baseSpeed 0.5→0.35（单帧位移更小）
- spiralStrength 1.2→0.8, noiseStrength 0.6→0.35（弯曲幅度降低）
- centralGlow: true→false（关闭每帧创建径向渐变）
- pulseAmplitude 0.35→0.25

### v2.2 修复角落马赛克 bug

用户反馈鼠标快速移动到四个角时出现巨大马赛克块。根因：`setOrigin` 改变 origin 后，每颗粒子的新 `pos` 是相对新 origin 算出的（`originX + cos*dist`），但 `prevpos` 还是旧 origin 附近的旧位置，画出来就是横跨屏幕的超级长线段，lineWidth 又随 moveDist 暴涨，所以呈马赛克。

修复 `public/starfield.js`：
- `setOrigin` / `setOriginX` / `setOriginY` 调用时同步 `syncPrevPos()`，把所有 star 的 prevpos 更新为当前 pos，避免轨迹断裂
- `lineWidth` 加 `Math.min(..., 3)` 上限保险，防止帧率抖动时 moveDist 暴涨
