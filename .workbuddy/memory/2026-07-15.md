# 2026-07-15 工作日志

## 修复 UI 三个问题

### 1. card 背景太深
- 文件：`src/styles/globals.css`
- `.card` 背景从 `rgba(255,255,255,0.12)` 改为 `0.06`，边框 alpha 从 `0.18` 改为 `0.12`，让磨砂卡片更通透

### 2. 导航默认选中状态错误
- 文件：`src/components/nav-card.tsx`
- `hoveredIndex` 初始值 `0` → `-1`，默认无选中
- 删除 icons 模式下自动 setHoveredIndex(activeIndex) 的 useEffect
- 新增 pathname 变化时重置 hoveredIndex 为 -1 的 useEffect（避免跳转后残留高亮）
- motion.div 高亮背景的 style 增加 `opacity: hoveredIndex < 0 ? 0 : 1`

### 3. 文章列表时间手机端换行
- 文件：`src/app/blog/page.tsx`
- 日期 span 从 `w-[44px]` → `w-[52px]`，并加 `whitespace-nowrap` 防止换行

### 4. 修复"点击文章后导航按钮应选中"（用户反馈）
- 同一文件 `src/components/nav-card.tsx`
- `activeIndex` 改为前缀匹配：`pathname === item.href || pathname.startsWith(item.href + '/')`，让 `/blog/[id]` 详情页也激活"近期文章"
- 引入 `displayedIndex = hoveredIndex >= 0 ? hoveredIndex : activeIndex ?? -1`，统一高亮判定
- `motion.div` 高亮背景、图标 active 状态、文本高亮都改用 `displayedIndex`
- 给 Link 加 `onMouseLeave={() => setHoveredIndex(-1)}`，桌面端 hover 离开后回落到路径激活
