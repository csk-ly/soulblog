# 2025-07-14 工作日志

## 卡片掠影（shimmer）效果优化

用户反馈卡片 shimmer 掠影太粗、持续时间太长，希望"快速亮一下"。

修改 `src/styles/globals.css` 中 `.card-shimmer::after` 和 `@keyframes card-shimmer-sweep`：

1. **blur 收窄**：`blur(40px)` → `blur(10px)`，光带从粗散变为细锐
2. **动画提速**：`5s linear` → `1.2s ease-out`，5 秒变 1.2 秒
3. **渐变光带收紧**：彩色区域从 20%-80%（60% 宽度）收窄到 35%-65%（30% 宽度），形成窄光条
4. **不透明窗口缩短**：满亮从 20%-80%（3 秒）改为 15%-55%（0.48 秒），快速亮快速灭
5. **颜色饱和度补偿**：因 blur 降低，color-mix 透明度从 40%-70% 提到 50%-60%，保证可见度

触发间隔 `SHIMMER_INTERVAL_MS = 10000` 保持不变（10 秒一张卡片闪一下，节奏合适）。

## 粒子背景 v3.0：双层架构 + 性能修复

用户反馈：鼠标附近要银河旋臂效果、整体背景要慢悠悠星空、越来越卡。

**卡顿根因**：每帧每粒子都做 `rgbToHsl` + `hslToRgb` + `parseRGBA`（正则匹配）+ Perlin 噪声，200 粒子 × 60fps = 每秒 2.4 万次颜色转换 + 1.2 万次噪声计算。

**彻底重写 `public/starfield.js` 为 v3.0 双层架构**：

1. **Layer 1 — 背景星空（150 颗）**：固定在屏幕上随机分布，只做 twinkle（alpha 正弦呼吸）+ 微飘移，用 `fillRect` 渲染（1px 点），无 stroke、无噪声、无 HSL 转换
2. **Layer 2 — 银河旋臂（80 颗）**：绕鼠标螺旋旋转，带 glow stroke + 加法混合
3. **颜色预计算**：启动时构建 32 色调色板（`buildPalette`），运行时按 index 取色，零 HSL 转换
4. **Perlin 噪声**：仅 galaxy 层使用，且 `noiseStrength` 降到 0.2
5. **背景层用 `source-over`**，仅 galaxy 层用 `lighter` 加法混合
6. `canvasColor` 改为 `rgb(2,2,8)` 深蓝黑，更有星空感

`starfield.tsx` 参数更新：`numStars` 200→80（仅 galaxy），新增 `bgStars: 150`，`spiralStrength` 0.35→0.5，`maxSpawnRadius` 1800→800（galaxy 粒子集中在鼠标附近），`canvasColor` → `rgb(2,2,8)`。

## 粒子背景 v4.0：双轴彻底分离（背景=穿越星空 / 鼠标=银河系）

用户反馈：背景没有移动效果（应为我原本的"穿越星空"），鼠标位置需要出现银河系特效。

**彻底重写为两个独立 axis**：

### Layer 1 — 背景"穿越星空"（220 颗）
- 锚点固定在屏幕中心（不跟鼠标）
- 每颗星有 angle + distance + speed，从中心向外匀速飞出
- 飞出 `warpMaxRadius: 1600` 后在中心重生（新的随机 angle），形成不断从消失点涌出的效果
- 速度 `0.22-0.37 px/ms`，约 7-10 秒横穿屏幕
- 中心 80px 内淡入、远端 22% 区域淡出，呈现"消失点"透视感
- 线宽随距离从 `0.6x` 渐变到 `1.4x`，远端更粗加强纵深
- 调色板 `bgPalette`：16 色冷白偏蓝（l 0.72-0.98）

### Layer 2 — 鼠标位置银河系（130 颗）
- 锚点 = 鼠标位置（`mousemove` 实时更新 `setOrigin`，已加 `syncPrevPos` 防跳变马赛克）
- **对数螺旋结构**：`θ = armIndex * π + (1/armPitch) * ln(r/coreRadius) + jitter`
  - `armCount: 2`（2 条旋臂，类银河系）
  - `armPitch: 0.42`（从 28px 旋到 340px 约转 165°，明显螺旋）
  - `armIndex` 0/1 决定所属旋臂，`jitter ±0.175` 避免完美曲线
- **核心光球**：
  - 18% 粒子被随机分配到 `coreRadius: 28` 内的核心区，颜色为 `corePalette`（暖黄→琥珀，hsl 48°→30°）
  - 每帧在鼠标位置画一个半径 130px 的径向渐变光晕（`rgba(255,240,200,0.45)` 中心 → 0 边缘），`lighter` 加法混合
- **旋臂粒子**：`armPalette` 24 色（80% 冷蓝青 hsl 200°+、20% 粉色 hsl 340° 模拟 HII 活跃区）
- **运动**：所有粒子按 `rotationSpeed: 0.0003 rad/ms` 同步公转（约 0.017°/s，慢悠悠）
- 渲染：每颗星双线宽描边（外圈 glow alpha 0.18 ×3 倍线宽 + 内核），`lighter` 加法混合

### 性能优化
- **彻底移除 Perlin 噪声**：之前 v3.0 仍保留部分噪声，现在是零噪声
- 颜色调色板在 setup 时一次性构建，运行时只查表
- 背景层 `source-over` 单线宽，银河层 `lighter` 双线宽
- 鼠标移动时 `syncPrevPos` 同步粒子 prev 位置，避免跳变时画超长线（之前已修）

## 粒子背景 v5.0：状态机（静止=银河 / 移动=彗星）

用户反馈三个需求：
1. 鼠标静止 500ms 后才出现银河慢悠悠旋转
2. 鼠标移动时变成彗星跟随动画
3. 背景星空要非常缓慢移动

**彻底重写 `public/starfield.js` 为 v5.0 三层架构 + 状态机**：

### 状态机
- `setOrigin(x, y)` 被调用时记录 `lastMouseMoveTime` 和鼠标速度（`mouseVelX/Y`）
- 每帧检查 `isIdle = (timestamp - lastMouseMoveTime) > 500`
- `galaxyAlpha` 和 `cometAlpha` 通过 lerp 交叉淡入淡出（`fadeSpeed: 0.05`）
- 鼠标速度每帧衰减 `*= 0.85`，低于 1 时 `isMoving = false`，停止生成彗星粒子

### Layer 1 — 背景慢速星空（180 颗，始终运行）
- `warpBaseSpeed: 0.22 → 0.05`（速度降低 4 倍多，非常缓慢）
- `warpStars: 220 → 180`，`warpMaxRadius: 1600 → 1400`
- 其他逻辑不变：从屏幕中心向外径向飞出，飞出后在中心重生

### Layer 2 — 银河系（静止 500ms 后淡入）
- 始终更新位置（保证旋转连续），但仅当 `galaxyAlpha > 0.01` 时绘制
- 所有 alpha 乘以 `galaxyAlpha`，实现平滑淡入淡出
- 参数不变：120 颗，2 旋臂，`rotationSpeed: 0.0002`（比 v4.0 更慢）
- **v5.1 关键修复**：在银河绘制前用不透明黑矩形覆盖银河区域（`armOuterRadius + coreGlowRadius*0.5` 半径），避免 55% 拖尾 fade 抵消 `lighter` 加法混合的亮度
- 银河粒子 `baseAlpha`：核心 1.0 / 旋臂 0.9，glow halo 系数 0.18→0.32，lineWidth 上限 3→4
- 核心光晕强度提升：0.45→0.75 / 0.22→0.45 / 0.10→0.20
- `galaxyAlpha` 淡入加速：fadeSpeed 0.05→0.12（拆开自 comet 的 0.05）
- **v5.2 彗星尾巴渲染**：旋臂粒子改为沿切线方向画 createLinearGradient 渐变拖尾（`trailLen = 30 + radius * 0.35`，外圈更长），头部画亮圆点；核心粒子改为实心圆点+软光晕；`galaxyStars` 120→180

### Layer 3 — 彗星跟随（移动时淡入）
- **彗星粒子池**：预分配 100 个 `CometParticle`，环形复用（`cometPoolIdx`），零 GC
- **生成**：鼠标移动且速度 > 1 时，每帧生成 3 个粒子，位置 = 鼠标当前位置，速度 = 反向鼠标移动方向 + 随机散射
- **生命周期**：`cometParticleLife: 800ms`，每帧 `life -= dt*16.67/life`，life ≤ 0 回收
- **渲染**：双线宽 stroke（glow ×4 + core ×1.5），`lighter` 加法混合
- **彗星头**：鼠标位置画径向渐变光晕（`cometHeadRadius: 30`，暖白→琥珀→透明）+ 2px 亮核

### v5.0 bug 修复：银河不显示 + 移动闪现
1. **银河不可见**：`GalaxyStar.draw` 中 alpha 按 `moveDist/4` 算，但 `rotationSpeed: 0.0002` 极慢时核心粒子每帧只移动 0.09px → alpha=0.023 几乎不可见。改为固定 `baseAlpha`（核心 0.85 / 旋臂 0.55）× `alphaMul`，不依赖移动距离
2. **移动时闪现银河**：鼠标移动时 `originX/Y` 跳变，`galaxyAlpha` 还在淡出中，粒子从旧位置画到新位置形成长条闪现。`setOrigin` 改为调用 `repositionGalaxy()` 立即用新 origin 重算所有银河粒子位置并同步 `px/py`，使下一帧 `moveDist` 只有旋转增量（极小），不会产生闪现
